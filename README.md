# Community Dev Toolkit 🛠️

An open-source starter kit to help new developers learn Git, GitHub, and build their first projects.

> Built for the community, by the community. Contributions welcome!

## ✨ What's inside?

- `resources/learning-roadmap.md` - Free learning path from zero to first job
- `templates/starter-html/` - Clean starter website template
- `templates/readme-template.md` - Reusable README template for your projects
- `CONTRIBUTING.md` - How to contribute (good first issue friendly)

## 🚀 Quick Start

```bash
git clone https://github.com/booss4541-alt/community-dev-toolkit.git
cd community-dev-toolkit
open templates/starter-html/index.html
```
