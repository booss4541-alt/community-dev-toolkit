# عدة المطور للمجتمع 🛠️ | Community Dev Toolkit

مجموعة مفتوحة المصدر لمساعدة المطورين الجدد على تعلم Git و GitHub وبناء أول مشاريعهم.

> صُنعت للمجتمع، بواسطة المجتمع. مساهماتكم مرحب بها!

## ✨ وش فيها؟

- `learning-roadmap.md` - خارطة تعلم مجانية من الصفر لأول وظيفة
- `templates/starter-html/` - قالب موقع نظيف للبداية
- `templates/readme-template.md` - قالب README جاهز لمشاريعك
- `CONTRIBUTING.md` - كيف تساهم (مناسب للمبتدئين)

## 🚀 البداية السريعة

```bash
git clone https://github.com/booss4541-alt/community-dev-toolkit.git
cd community-dev-toolkit
open templates/starter-html/index.html
```

## 🤝 كيف تساهم؟

نحب مساهماتكم! اقرأ [CONTRIBUTING.md](CONTRIBUTING.md) أولاً.
- صحح أخطاء إملائية
- أضف مصادر تعليمية مجانية
- ترجم للغتك
- أضف قوالب جديدة

كل المساهمين سيتم ذكرهم هنا. 🙏
