# Contributing to Community Dev Toolkit 🤝

Thank you for considering contributing! This project exists to help beginners.

## How to Contribute
1. Fork the repo
2. Create a branch: `git checkout -b add-my-resource`
3. Make your change (add a resource, fix typo, improve template)
4. Commit: `git commit -m "Add: free CSS course"`
5. Push and open a Pull Request

## Good First Issues
- Add free learning resources (courses, docs, YouTube)
- Improve English grammar
- Add translations (Arabic, Spanish, etc.)
- Add new starter templates

## Code of Conduct
Be kind, respectful, and welcoming. No spam, no hate. We review all PRs within 48h.

Thank you! 🙏
